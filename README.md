## 🚀 Featured Project

### ⚡ Cutting Monitoring System (CMS)

> A full-stack, real-time industrial production & machine tracking web app for cutting workshops (**Laser, Plasma, Oxy-fuel**). Tracks cutting operations live, records retroactive sheets, computes material consumption & machine runtimes, and exports printable *Bons de préparation* + PDF reports.

| | |
|---|---|
| ⏱️ **Live tracking** | Machine timers with single-operation-per-machine enforcement & 5s polling sync |
| 📋 **Job records** | Program, BL number, operator, client, material, thickness, weight |
| ✍️ **Retroactive entry** | Manual sheets with custom start–end timestamps |
| 📊 **Dashboard KPIs** | Operations, running machines, completed jobs, processed weight |
| 🖨️ **Print & PDF** | One-click *Bon de préparation* export with enterprise branding |
| 🔒 **Admin area** | Role-protected management + full history |
| 💾 **Dual database** | SQLite (local) or PostgreSQL (cloud / Railway) |

**Tech:** React 19 · Vite · Node.js · Express · SQLite / PostgreSQL · Railway

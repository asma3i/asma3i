## 🚀 Featured Project

### ⚡ Cutting Monitoring System (CMS)

> A full-stack, real-time industrial production & machine tracking web app for cutting workshops (**Laser, Plasma, Oxy-fuel**). Tracks cutting operations live, records retroactive sheets, computes material consumption & machine runtimes, and exports printable *Bons de préparation* + PDF reports.

**Highlights**
- ⏱️ Live machine timers with single-operation-per-machine enforcement & 5s polling sync
- 📋 Job tracking: program, BL number, operator, client, material, thickness, weight
- ✍️ Manual / retroactive entry with custom start–end timestamps
- 📊 Dashboard KPIs: operations, running machines, completed jobs, processed weight
- 🖨️ One-click PDF / print export (*Bon de préparation*) with enterprise branding
- 🔒 Role-protected admin area + history management
- 💾 Dual DB engine: SQLite (local) or PostgreSQL (cloud / Railway)

**Tech:** React 19 · Vite 8 · Node.js · Express 5 · SQLite / PostgreSQL · Railway
